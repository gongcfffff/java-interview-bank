# Java 面试题库

八章共 602 道题，包含 Java 基础、Java 集合、Java 并发、JVM、Spring、MySQL、Redis 和消息队列。

## 本地使用

下载或克隆整个仓库，在浏览器中打开根目录的 `index.html`。题解、搜索、知识图谱和刷题可以离线使用。学习进度保存在当前浏览器。

## 更新题库

`data/questions.js` 是页面读取的生成文件。原始 Java 五章、扩展三章和口述稿分别位于 `tools/sources/java-365.html`、`tools/backend-chapters.json` 和 `tools/interview-answers.json`。修改后运行：

```sh
node tools/build-data.js
```

原始题目目录参考小林 Coding。题目页提供对应的原文链接。
